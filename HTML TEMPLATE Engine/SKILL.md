# HTML Template Engine

Use this skill when creating a single-file HTML page that someone can open, edit, upload, or give away without a build step.

## Output Rules

- Create one self-contained `.html` file.
- Put CSS in a single `<style>` tag.
- Use semantic HTML: `header`, `main`, `section`, `article`, `footer`.
- Keep JavaScript optional and tiny; prefer CSS-first interaction.
- Use responsive CSS so the file works from 360px mobile to desktop.
- Keep copy editable and practical, not placeholder lorem ipsum.
- Preserve the noCode.media visual language unless a template needs its own domain-specific tone: monochrome structure, red highlight, sharp labels, strong spacing, and no decorative clutter.

## Template Pattern

1. Define CSS variables first.
2. Add a compact hero with a literal offer or use case.
3. Show the useful thing immediately: cards, table, checklist, pricing, directory, portal, timeline, or download list.
4. Include one clear CTA.
5. Add a short footer with edit notes or attribution.
